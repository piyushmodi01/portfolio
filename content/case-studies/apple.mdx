<Chapter

  title="The Environment"
  intro="Most products fight for a user's time. This one is part of how thousands of employees do their jobs every day."

<Prose>
As a contract designer, I work on an internal platform thousands of employees use every day to get their jobs done. I sit inside the product team, working alongside engineering and PMs running several projects at once.

The people using this aren't strangers. They're colleagues doing real work. That changes everything. There's no marketing, no onboarding, no star rating — you earn trust by being useful, over and over.
</Prose>

<Chapter
  number="02"
  title="The System I Contribute To"
  intro="Every product in this org builds on a shared design system."
/>

<Pull accent>
  One decision at the foundation shows up in everything built on top of it.

<Prose>
I helped build and maintain the org's shared design system — the foundation every product, screen, and component is built on. Getting it right there matters more than getting it right anywhere else, because it touches everything at once.
</Prose>

<Chapter
  title="A Tool Built for Design, Adopted by Everyone"
  intro="Accessibility has always been design's responsibility. The goal was to make it everyone's habit."
/>

<Prose>
I build tools that make it easier for design and engineering to meet the accessibility standards Apple holds closely. The Accessibility Checker started as a personal one — a fast way to run contrast checks and accessibility audits without leaving my workflow. I built it as a browser extension, a Sketch plugin, and a bookmarklet.

Then something I didn't plan happened: PMs started running it before design reviews, engineers started running it before code review. Accessibility stopped being design's job alone.
</Prose>

<Pull accent>
  Accessibility is design's job. The tool just made it easier for everyone else to participate.
</Pull>

<Chapter
  number="04"
  title="What Shipped"
  intro="Several products, shipped in parallel. Specifics are confidential — the shape of the work isn't."

<Prose>
Several products shipped or moved to engineering during this engagement, all under NDA. Same pattern each time: learn how people actually work, fix where the interface didn't match that, and redesign around the real workflow. The fix was usually simpler than expected. It usually is.
</Prose>
